# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated: static HTML/CSS with no build step, served as plain files (e.g. GitHub Pages). Chosen because the site is a small set of research pages, the repository already ships plain HTML, and figures are produced offline in R rather than rendered in the browser. Revisit only if interactive data views become a requirement.

## Users

Primary: lab members, prospective PIs, and recruiters/hiring reviewers evaluating the author's research. They arrive from a link (CV, email, application), skim on desktop or phone, and need to grasp the question, method, and key finding quickly, then judge the rigor of the analysis.

## Product Purpose

A research-results page sharing a Parkinson's disease substantia nigra (SN) proteomics analysis focused on PON1 and PON2 expression. It replaces the previous "2023 버킷리스트" practice page, which is retired. Success means a reviewer understands what was compared, what was found for PON1/PON2, and trusts how it was done.

## Positioning

A first-hand analysis, not a literature summary: the page presents the author's own differential-expression analysis of SN proteomics data (PD vs Healthy), with the exact method and thresholds stated, and the analysis code in the same repository.

## Operating Context

- Analysis is run offline in R (`SN_PON1_PON2_analysis.R`) on `SN protein data.xlsx` (normalized intensities; not in the repository).
- Method: limma differential expression, contrast PD − Healthy; significance defined as adj.P < 0.05 and |log2FC| > 0.58.
- Outputs: `limma_results_all.csv`, a side-by-side PON1/PON2 boxplot with p / adj.p annotation and group n, and a full volcano plot with PON1 and PON2 highlighted (written to `SN_PON_output/`).
- Figures are exported from R and embedded in the page as static images.

## Capabilities and Constraints

- Publish: figures (boxplot, volcano) and summary statistics (log2FC, p, adj.p, group sizes, up/down counts).
- Do not publish: the raw data file or per-sample values.
- No personal information (name, affiliation, contact) on the site; research content only.
- Open: whether the full DE results table is shown or linked (it is derived from raw data; default to summary only unless the author approves).
- Open: whether the page is in Korean, English, or both.

## Evidence on Hand

- `SN_PON1_PON2_analysis.R`: full analysis code (repository root).
- Figures and result CSV: not yet in the repository; must be generated by running the script and added. Future work must not fabricate numbers, p-values, sample sizes, or plots.
- No publications, citations, collaborators, or funding are recorded; do not invent any.

## Product Principles

1. Finding first: the PON1/PON2 result is visible before the methods.
2. Show the method exactly: contrast, test, thresholds, and n are stated as run, so a reviewer can judge rigor.
3. Real numbers only: every statistic on the page traces to the script's output.
4. Protect the data: summaries and figures yes, raw or per-sample data no.
5. Research, not résumé: no personal details; the work speaks for itself.

## Accessibility & Inclusion

Figures need text equivalents (alt text stating the key comparison and result). Group colors in the plots (Healthy vs PD; PD is `#D73027`) must not be the only way the groups are distinguished.
